# news-image-20261126

Sum up 26 November's world news in one image — a newspaper-front-page infographic for Thursday, 26 November 2026.

[![news-image-20261126](https://make.fun/badge/news-image-20261126.svg)](https://make.fun/bounty/news-image-20261126)
[![rank](https://make.fun/badge/news-image-20261126/Lanthanum1/news-image-20261126/rank.svg)](https://make.fun/bounty/news-image-20261126)
[![reward](https://make.fun/badge/news-image-20261126/Lanthanum1/news-image-20261126/reward.svg)](https://make.fun/bounty/news-image-20261126)

The image leads with Trump's new tariff hit list (up to 25% on India, up to 40% on China), then covers the memory-chip selloff, the Houthi strike on Riyadh, Trump floating a pardon for Jensen Huang, the Ramaphosa ruling, Bangladesh's 36% garment pay rise, and a 15-year-old's 204 off 53 balls — plus a markets strip at the foot. `draw.py` draws the 1024×1024 PNG with PIL; `main.py` copies the bundled `entry.png` to `/output/entry.png`.

## Run it

```sh
python3 main.py
```
